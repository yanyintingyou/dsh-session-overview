# dsh-session-overview

[English](README.md) | [中文](README.zh.md)

DeepSeek Harness（dsh）的 Web 插件：在会话头部加一个「概览」视图页，看清整段会话发生了什么、花了多少钱。

## 页面内容

顶部五个指标：总词元、会话费用（峰时/空闲拆分）、缓存命中、工具调用（失败数与用时）、轮次与步数（模型用时）。

下面依次是：

- **词元构成**：未缓存输入、缓存读取、缓存写入、输出，堆叠条加占比。
- **上下文占用**：最近一次请求的提示词与上下文窗口的占比，附系统提示词、工具定义、对话消息的估算构成。
- **工具与扩展**：按调用次数排序，标出内置 / MCP / 插件 / 技能，给出次数、失败数、累计用时；代码模式（PTC）子调用单独计数。
- **模型与费用**：每条路由的请求次数、提示词 → 输出词元、峰谷各自消耗，以及按官方价目算出的费用；卡片底部写明价目来源和无价目的路由。
- **技能**：加载过的技能及次数。
- **子代理**：本会话创建的直接子代理及其类型。
- **时间**：模型用时、工具用时、首字延迟均值、输出速度。
- **异常**：工具失败、轮次错误、中断、输出触顶、请求重试、上下文压缩的计数，最后一条错误信息单独列出。
- **逐轮明细**（页面最下方）：每轮一行，列出触发这一轮的提示词、步数、上下文、输出、缓存命中、模型与工具用时、该轮费用；展开后列出这一轮每一步调用的工具与次数、上下文、输出、缓存、首字延迟、输出速度、工具用时、该步费用。重试与中断的步单独标出。默认全部折叠，列表高度约容纳三轮，其余滚动查看。

## 数字从哪来

全部来自 Host 端的会话投影，翻页和压缩都不会改变结果：`tokenUsage`、`contextPressure`、`contextBreakdown`、`sessionStats`、`modelSelection`、`subagentCatalog`，以及本插件自带的 `sessionActivity`。

`sessionActivity` 按 `step/start`、`assistant/attempt`、`assistant/message`、`tool/call`、`tool/result`、`tool/ptc-dispatch*`、`turn/end`、`llm/retry`、`compaction/start` 逐事件折叠整段日志。工具调用与结果按 call id 配对；一直没有结果的调用在轮次结束时丢弃，不计入。

工具分类按名字判断：`mcp__` 前缀归 MCP，`skill` 归技能加载器，`CORE_TOOLS` 里的名字归内置工具，其余归插件。

## 费用怎么算

价目来自 DeepSeek 开放平台官方价格页（[模型 & 价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)），单位 元 / 百万 tokens，2026-08-17 起的峰谷价：

| 模型 | 缓存命中 | 缓存未命中 | 输出 |
|---|---|---|---|
| `deepseek-flash`（含旧名 `deepseek-v4-flash`、`deepseek-v4-flash-vision-exp`） | 峰 ¥0.04 / 谷 ¥0.02 | 峰 ¥2 / 谷 ¥1 | 峰 ¥8 / 谷 ¥4 |
| `deepseek-v4-pro` | 峰 ¥0.30 / 谷 ¥0.15 | 峰 ¥9 / 谷 ¥4.5 | 峰 ¥27 / 谷 ¥13.5 |

北京时间周一至周五 09:00–12:00、14:00–18:00 为高峰；其余时段（含周末、法定节假日全天）为空闲，空闲价为峰时价的一半。分档按每次请求的派发时间（`step/start`）判断，跨过 12:00 或 18:00 的长回复仍算在它开始时所属的时段；没有记录派发时间的请求退回 `assistant/message` 的落库时间。

法定节假日用 `index.js` 内置的 2026 年清单（国办发明电〔2025〕7号）。新一年度通知发布后，把日期补进 `HOLIDAYS`，同时把 `stateVersion` 加一，让已缓存的分档重算。

价目写在 `client.js` 的 `PRICES` 里。费用在页面侧用折叠好的峰谷词元桶乘价目表算出，改价目对整段历史生效，不需要重建投影缓存。

未包含：联网搜索与网页抓取的按次费用（官方 ¥5 / 1000 次，与 token 计费分开）、非 DeepSeek 模型。没有价目的路由仍显示词元，费用留空，不计入总额。

## 安装

1. 把本目录放在一个固定的位置。
2. 在 dsh 里用 `plugin_manager` 的 `install_bundle`，目标填绝对路径；或者 **Plugins → Add plugin** 选择本目录。
3. 刷新页面，会话头部出现「概览」标签。

插件带两个半边：`index.js` 注册 `sessionActivity` 投影，`client.js` 渲染视图。

## 限制

- 上下文构成是本地估算，和占用百分比不会严格相等。
- DSH 升级后如有新增内置工具，把名字补进 `CORE_TOOLS`，分类才会正确。
- 纯只读：不写会话、不发请求、不改配置。
- 在 dsh `0.2.2-rc.5`（Desktop，Windows）上测试。包没有声明 `engines.dsh`。
