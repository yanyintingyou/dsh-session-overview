# dsh-session-overview

[English](README.md) | [中文](README.zh.md)

给 DeepSeek Harness（dsh）的 Web 界面加一个「概览」标签页：一段会话里发生了什么、花了多少钱，都在这一页。

## 页面内容

顶部五个指标：总词元、按峰谷拆分的会话费用、缓存命中比例、工具调用（失败次数与累计用时）、轮次 / 步数（模型用时）。

往下是这些卡片：

- 词元构成：未缓存输入、缓存读取、缓存写入、输出四段堆叠条，附各自占比。
- 上下文占用：最近一次请求的提示词占上下文窗口多少，再估算其中系统提示词、工具定义、对话消息各占多少。
- 工具与扩展：按调用次数排序，最多显示 8 个，一个工具一行，写着调用次数、失败次数、累计用时和类型（内置 / MCP / 插件 / 技能）。代码模式（PTC）的子调用单独计数。
- 模型与费用：每条路由的请求次数、提示词与输出词元、峰谷各自的消耗，以及按官方价目算出的费用；卡片底部注明价目来源，有查不到价目的路由也在这里说一声。
- 子代理：本会话直接创建的子代理，带类型。
- 技能：加载过哪些技能、各几次。
- 时间：模型用时、工具用时、首字延迟均值、输出速度。
- 异常：工具失败、轮次报错、中断、输出触顶、请求重试、上下文压缩各有几次，最后一条错误信息单独列。

页面最下面是逐轮明细。一轮一行：触发这一轮的提示词、步数、上下文、输出、缓存命中、模型用时与工具用时、整轮费用。展开看这一轮的每一步，调了哪些工具各几次、上下文、输出、缓存、首字延迟、输出速度、工具用时、这一步的费用，重试和中断的步带标记。默认全部折叠，框子约放得下三轮，再多用滚轮翻。

## 数字从哪来

数字全来自 Host 端的会话投影，聊天记录翻页、历史压缩都不影响结果：`tokenUsage`、`contextPressure`、`contextBreakdown`、`sessionStats`、`modelSelection`、`subagentCatalog`，再加上插件自己的 `sessionActivity`。

`sessionActivity` 把整段日志里的 `step/start`、`assistant/attempt`、`assistant/message`、`tool/call`、`tool/result`、`tool/ptc-dispatch*`、`turn/end`、`llm/retry`、`compaction/start` 折成一份状态。工具调用按 call id 和结果配对，等到轮次结束还没结果的调用直接丢掉。

工具按名字分类：`mcp__` 开头归 MCP，叫 `skill` 的归技能加载器，`CORE_TOOLS` 里列的是内置工具，剩下的算插件。

## 费用怎么算

价目抄自 DeepSeek 开放平台的[模型 & 价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)，单位是元 / 百万 tokens，2026-08-17 起分峰谷：

| 模型 | 缓存命中 | 缓存未命中 | 输出 |
|---|---|---|---|
| `deepseek-flash`（含旧名 `deepseek-v4-flash`、`deepseek-v4-flash-vision-exp`） | 峰 ¥0.04 / 谷 ¥0.02 | 峰 ¥2 / 谷 ¥1 | 峰 ¥8 / 谷 ¥4 |
| `deepseek-v4-pro` | 峰 ¥0.30 / 谷 ¥0.15 | 峰 ¥9 / 谷 ¥4.5 | 峰 ¥27 / 谷 ¥13.5 |

北京时间周一到周五 09:00–12:00、14:00–18:00 是高峰，其余时间走空闲价，空闲价是峰时价的一半。周末和法定节假日全天按空闲算。每条请求按派发时间（`step/start`）定档，回复写得再久、跨过 12:00 或 18:00，也还留在开始时的那一档；日志里没有派发时间的，退回用 `assistant/message` 的落库时间。

法定节假日用 `index.js` 里内置的 2026 年清单（国办发明电〔2025〕7号）。下一年度的通知出来后，把日期补进 `HOLIDAYS`，再把 `stateVersion` 加一，已缓存的折叠结果就会重算。

价目表在 `client.js` 的 `PRICES` 里。费用是页面拿折叠好的峰谷词元桶乘价目算出来的，改价目对整段历史立刻生效，不用重建投影缓存。

没算进来的有两样：联网搜索和网页抓取的按次费用（官方 ¥5 / 1000 次，跟 token 分开计），以及非 DeepSeek 的模型。查不到价目的路由照样显示词元和请求次数，费用那一栏空着，也不进总额。

## 安装

把本目录放到一个固定的位置，然后在 dsh 里用 `plugin_manager` 的 `install_bundle` 填绝对路径，或者走 Plugins → Add plugin 选这个目录。刷新页面，会话头部会多出「概览」标签。

插件分两半：`index.js` 注册 `sessionActivity` 投影，`client.js` 渲染视图。

## 限制

- 上下文构成是本地估的，跟占用百分比对不上很正常。
- DSH 升级后要是加了新的内置工具，把名字补进 `CORE_TOOLS`，不然它们会被算成插件工具。
- 插件只读：不写会话、不发模型请求、不改配置。
- 只在 dsh `0.2.2-rc.5`（Desktop，Windows）上试过，包没有声明 `engines.dsh`。
